NO-CACHE DOES NOT MEAN NO CACHE
VALUE 01 / 3

no-cache

It does cache. It just asks the server first.

✗ PEOPLE THINK
no-cache = do not cache?
VISIT 1
download 20 KB
VISIT 2
download 20 KB again
No copy kept, so every visit pays in full.
MYTHNothing is stored. Ever.
✓ WHAT IT DOES
Cache-Control: no-cache
VISIT 1
download 20 KB
copy saved
VISIT 2
asks: changed?
304, no body
Unchanged? The copy is reused.
FACTStored, then checked with the server before each reuse.
THE HEADERS
// index.html response
Cache-Control: no-cache
ETag: "v42"
// next visit the browser asks:
If-None-Match: "v42"
// server answers: 304 Not Modified, no body

VALUE 03 / 3

max-age=60

Reuse it for 60 seconds without asking.

✗ PEOPLE THINK
a 60 second timer?
AT 60 s
page reloads itself
AT 120 s
page reloads itself
Nothing reloads by itself. It only sets how long a copy stays fresh.
MYTHThe page reloads every 60 seconds.
✓ WHAT IT DOES
Cache-Control: max-age=60
AT 0 s
download 20 KB
copy saved
AT 30 s
from cache
0 requests
AT 75 s (stale)
asks: changed?
304 or new file
FACTFresh for 60 s. After that, it checks again.
THE HEADERS
// GET /api/products response
Cache-Control: max-age=60
// 0 to 60 s: served from cache, no request
// after 60 s: stale, browser checks again
